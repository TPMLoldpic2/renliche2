人力車 AR 明信片｜觸控與追蹤平滑更新版

使用方法
1. 解壓縮，將裡面的全部檔案與資料夾上傳到 GitHub Main，與 index.html 放在同一層。保留 assets、vendor 資料夾結構。
2. GitHub Pages 使用 main / root；網站更新後，以手機開啟 HTTPS 網址並允許相機。
3. 按「開始掃描明信片」，對準包內 print_photo.png。可列印，或用另一台螢幕顯示。請保留整張照片，避免裁切、反光。
4. 辨識照片後，拉車人邁步、人力車沿街道循環行進，兩個車輪轉動，乘客有細微頭部及手部動作。
5. 在 AR 畫面上雙指張合可放大／縮小模型，雙指轉動或單指左右拖曳可旋轉。兩指可以同時縮放與旋轉。大小範圍為 0.25 至 2.5；這是模型縮放。
6. 「調整模型」可暫停／繼續動畫。速度、大小、方向及高度已改為按鈕，不需要滑軌。
7. 「恢復預設」會還原大小、方向、高度及速度，並恢復動畫播放。「結束掃描」會關閉相機。照片離開鏡頭時，模型隱藏且暫停動畫。

已包含 INDEX、GLB、照片辨識檔、動畫程式及必要函式庫，不需要自行串接。
首頁與操作介面沿用前一版。這是獨立的人力車版本。

追蹤平滑設定
filterMinCF: 0.001；filterBeta: 20（原預設 1000）。warmupTolerance、missTolerance 改為 8。
此版本增加追蹤平滑，取捨是移動手機時可能跟隨較慢。遺失容忍只減少短暫閃現，不會直接消除姿態抖動。
已以同一套 MindAR 濾波器做固定位置的合成雜訊測試，這不代表手機上的實際抖動幅度。仍須在你的手機與照片上測試；未承諾完全不晃。

手機相機權限及實際辨識穩定度仍需實機確認。

更新舊網站時請完整替換檔案；如仍看到舊畫面，可重新整理或清除快取。
函式庫：A-Frame 1.6.0、MindAR 1.2.5。授權檔在 vendor。
